my-jarvis プライバシーポリシー

最終更新: 2026-10-25

my-jarvis は、開発者本人だけが自分の Mac で使う個人用のアプリです。利用者は開発者本人 1 人です。

読むデータ

  • Google カレンダー(スコープ calendar.events): 本人が選んだカレンダーの予定を読みます。予定の追加・変更・取り消しは、本人が承認したときだけ行います。
  • Gmail(スコープ gmail.readonly): 本人の受信トレイを読むだけです。送信、削除、変更はしません。

使い方と送り先

  • 読んだ予定とメールは、本人への答えや要約を作るためだけに使います。
  • 答えを作るために、必要な範囲を Anthropic の Claude API に送ります。Claude API は送った内容を学習に使いません。
  • 読んだ中身はそのまま保存しません。本人の手元(Mac)に要点だけを残し、その控えを暗号化して本人の非公開の GitHub リポジトリに置きます。
  • 第三者に売ること、広告に使うこと、人が読むことはありません。上に書いた以外の外部へは送りません。

Google のポリシーへの準拠

my-jarvis が Google API から受け取った情報の使用と、他のアプリへの移転は、Limited Use の要件を含む Google API Services User Data Policy に従います。

取り消しと削除

本人は Google アカウントの「サードパーティ製のアプリとサービス」 から、いつでも my-jarvis の許可を取り消せます。手元と控えのデータは、本人がいつでも完全に消せます。

連絡先

English

my-jarvis is a personal app used only by its developer on their own Mac. The developer is its only user.

  • Google Calendar (calendar.events): reads events in calendars the developer selects; adds, changes or cancels events only with the developer's approval.
  • Gmail (gmail.readonly): reads the developer's inbox only; never sends, deletes or modifies email.
  • The data is used only to produce answers and summaries for the developer. The necessary parts are sent to Anthropic's Claude API, which does not train on them. Only summaries are kept on the developer's Mac, with an encrypted backup in the developer's private GitHub repository. Data is never sold, used for advertising, read by humans, or sent anywhere else.
  • my-jarvis's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • Contact: github.com/saionhere
  • Access can be revoked at any time from the Google Account's third-party apps page, and all local and backup data can be deleted by the developer at any time.
